# Кодекс поведінки

## Обіцянка

Ми робимо участь у цьому проєкті вільною від переслідувань для кожного, незалежно від віку, стану здоровʼя, досвіду, освіти, зовнішності, національності, статі чи ідентичності.

## Норми

Що допомагає: повага до чужого часу, конкретний фідбек по роботі, а не по людині, готовність визнати помилку.

Що неприйнятне: образи, приниження, переслідування, публікація чужих приватних даних без дозволу, будь-яка поведінка, недоречна в професійному середовищі.

## Як повідомити

Про порушення повідомте приватним звітом через GitHub Security Advisories цього репозиторію, як описано в `SECURITY.md`. Кожне звернення розглядається приватно.
