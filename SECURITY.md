# Безпека / Security

Скіл не виконує код, не читає секретів і нічого не надсилає сам: останній крок завжди чернетка і явне «так» людини.
Якщо ви знайшли місце, де текст скіла можна використати для інʼєкції інструкцій, витоку даних або обходу підтвердження,
повідомте приватно.

Повідомлення йде приватним звітом через GitHub Security Advisories цього репозиторію (кнопка «Report a vulnerability»
у вкладці Security). Публічне ішʼю для вразливості не відкривайте, доки не буде виправлення. Окремої поштової адреси
поки немає; до її появи єдиний канал це GitHub.

---

The skill executes no code, reads no secrets, and never sends anything by itself: the last step is always a draft plus
an explicit human yes. If you find a way to use the skill text for instruction injection, data leakage, or confirmation
bypass, report it privately via GitHub Security Advisories on this repository ("Report a vulnerability" under the
Security tab). Please do not open a public issue for a vulnerability before a fix exists.
